My first header

In this activity you will create the header of your web page! The header is the top section of a site, where the name and a short introduction usually go.

Before you start, copy and paste the HTML code from the previous activity (or use the “Bring code from the previous activity” button).

In your HTML:

  • Add the <header></header> tags at the beginning of the <body>. Inside them:
    • Move the <h1> and the <p> you created in the previous activity.
    • Change the <h1> text to:
    • Change the <p> text to the following:

Welcome to my first website. Here you will find information about my interests, my projects and the things I am learning about programming.

Add styles in your CSS:

  • Copy and paste the following code to give the header some color:
header {
        background-color: #1E3A5F;
        color: #FFFFFF;
        padding: 20px;
      }

Check the result:

  • You should see a blue header with the title and the paragraph in white letters. When you finish, press Check.
