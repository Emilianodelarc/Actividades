My first header

In this activity you will create the header of your web page! The header is the top section of a site, where the name and a short introduction usually go.

Before you start, copy and paste the HTML code from the previous activity.

In your HTML:

  • Add the <header></header> tags inside the <body>. Inside them:
    • Add the <h1></h1> tags. Inside the tag, copy and paste the following text:
    • Below the <h1>, add the <p></p> tags. Inside, copy and paste the following text:

Welcome to my first website. Here you will find information about my interests, my projects and the things I am learning about programming.

Add styles in your CSS:

  • Copy and paste the following code to give the header some color:
header {
  background-color: #1E3A5F;
  color: #FFFFFF;
  padding: 20px;
}

Check the result:

  • When you run your page, you should see a blue header with the title and the paragraph in white letters.
